# 开发指南

## 产品定位

量潮机密云（qtcloud-secret）的定位是 **1Password 的团队协作版**，机密管理覆盖密码、证件、密钥与敏感信息等所有需要同一套安全架构处理的对象。

与面向个人用户的 1Password 不同，量潮机密云面向团队与企业组织，在个人机密管理的基础上，重点强化以下能力：

- **团队共享**：凭证、密钥与敏感信息可在团队内安全共享，支持按成员、角色、项目分组管理访问权限
- **权限与审计**：细粒度的访问控制与全生命周期审计，满足企业内部合规要求
- **组织级管理**：支持团队、项目的层级化组织，以及凭证的集中登记、轮换与回收
- **协作流程**：围绕敏感信息的申请、审批、使用、轮换形成标准化协作流程
- **私有化部署**：可在企业内网部署，数据主权归企业所有

简单来说：**1Password 解决"个人密码怎么管"，量潮机密云解决"团队的机密怎么一起管"。**
